Desktop app

Zuko for Windows

Protects Claude Code in the terminal and in VS Code. Adds clipboard and document masking.

Windows 10 and 1164-bit4.0 MB.exe installer
Download for Windows
  1. Run the installer. It needs no admin rights.
  2. If Windows says "Windows protected your PC", click More info, then Run anyway. The app is not code-signed yet.
  3. Open Zuko's Settings → Protection, switch on Hooks and Gateway, and click Apply. Full steps

Browser extension

Zuko for Chrome and Edge

Protects ChatGPT, claude.ai and DeepSeek. Works on its own or linked to the app.

ChromeEdge0.9 MB.zip
Download the extension
  1. Unzip it to a folder you will keep.
  2. Open chrome://extensions or edge://extensions and switch on Developer mode.
  3. Click Load unpacked and choose the Zuko-Extension folder. Full steps

What's in 0.1.1

Everything you need, nothing you don't.

Privacy

Masks 50+ secret formats and personal data before they leave your PC, and puts the real values back locally. Encrypted vault, tamper-evident audit log.

Control

Risk levels on every agent action, plain-English approval cards, hold-to-allow for risky ones, and your own blocked sites, folders and commands.

Everywhere you use AI

Claude Code in the terminal and VS Code, ChatGPT, claude.ai and DeepSeek, plus clipboard and document masking for any other app.

Requirements

Windows 10 or 11 (64-bit). Claude Code for agent protection. Chrome or Edge for the extension. Ollama is optional, for the local AI.
